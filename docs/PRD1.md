## 📁 一、产品概述

### 1.1 🎯 项目简介（名称 / 定位）

| 项目 | 内容 |
| --- | --- |
| **产品名称** | **ScienceX · AI 科研工作台** |
| **一句话定位** | 覆盖「选题 → 文献 → 实验 → 分析 → 写作 → 投稿 → 协作」科研全生命周期的 AI 工作台：对话即工作台，工具即智能体 |
| **产品形态** | Web SPA（前后端分离）+ 官网宣传页（含产品演示视频）+ 移动端自适应网页 |
| **核心理念** | 把科研中重复、琐碎、耗时的环节交给 AI 智能体，让研究者专注创新本身 |
| **差异化主张** | 竞品多为「单点工具」，ScienceX 以 AI 对话中枢 + 灵犀 Agent 引擎（8 种 Agent 模式、3 层记忆）串联全流程，数据可追溯、可协作、可复用，并支持任意 OpenAI 兼容模型接入与 MCP 工具编排 |

### 1.2 👥 用户与使用场景

| 用户角色 | 画像 | 核心诉求 | 典型场景 |
| --- | --- | --- | --- |
| 🎓 研究生 / 博士生 | 论文是毕业硬指标 | 快速入门选题、读懂英文文献、写出第一篇论文 | 开题前选题调研；组会前精读 5 篇论文；深夜改稿润色 |
| 🧑‍🏫 高校教师 / 科研人员 | 有课题、要发论文评职称 | 提产出、带团队、追前沿 | 审稿写基金、指导组会汇报、课题立项统筹 |
| 🧪 课题组 / 实验室 | 多人协作、知识难沉淀 | 共享文献库、统一汇报、经验传承 | 团队 RAG 知识库、协同阅读讨论、成果看板 |
| 🏢 企业研发人员 | 应用型研究重落地 | 技术调研、复现 SOTA、写技术报告 | 论文代码复现（DreamPaper）、选型调研 |
| 🧑‍🎨 跨学科研究者 | 需快速进入陌生领域 | 建立领域认知、术语翻译 | 思维导图 + 专家评审团快速摸清方向 |

**关键场景链路**：`选题灵感 → 文献阅读 → 实验设计 → 数据图表 → 论文写作 → 专家评审 → 投稿助手`，各环节产物自动沉淀至「课题空间」。

### 1.3 💡 痛点与价值

| 科研阶段 | 真实痛点 | ScienceX 价值点 | 量化收益（目标） |
| --- | --- | --- | --- |
| 选题 | 找不到方向、判断不了可行性 | 多源文献检索 + 选题推荐 + 可行性评估 + 开题报告 | 选题调研耗时 ↓60% |
| 读文献 | 英文阅读慢、读不懂、读了忘 | 中英对照翻译 + 思维导图 + 七段式总结 + 引用图谱 | 单篇精读耗时 ↓50% |
| 实验 | 参数乱记、方案拍脑袋 | 参数看板 + 消融/对比方案生成 + SOTA 对标 | 方案设计效率 ↑40% |
| 数据分析 | 不会画图、看不懂结果 | 科研图工作台（10 类图表模板 + 生图模型）+ AI 图表解读 | 出图+解读耗时 ↓70% |
| 写作 | 表达不地道、查重降重难 | 学术润色 + 双通道查重 + 保义降重 | 改稿轮次 ↓50% |
| 投稿 | 不了解期刊、错过 deadline | CCF 期刊大全 + 投稿倒计时 + 匹配推荐 | 投稿准备耗时 ↓40% |
| 协作 | 组会汇报累、导师意见散乱 | PPT 一键生成 + 导师建议归档 + 多智能体评审 | 组会准备耗时 ↓70% |
| 知识 | 资料散落各处、无法复用 | 课题空间 + 团队 RAG 知识库 | 知识可积累、可传承 |

### 1.4 🔍 竞品调研

| 竞品 | 定位 | 优势 | 不足 | ScienceX 差异化 |
| --- | --- | --- | --- | --- |
| SciSpace (Typeset) | 文献阅读/写作助手 | 阅读体验好、翻译强 | 工具分散、缺实验/投稿闭环 | 全流程闭环 + 实验/投稿模块 |
| Elicit | AI 文献综述 | 结构化抽取强 | 仅覆盖文献环节 | 从文献延伸到实验/写作/投递 |
| Consensus | 科学问答 | 基于论文的证据问答 | 无写作、无项目管理 | 问答 + 全流程工具一体化 |
| Connected Papers / ResearchRabbit | 引用图谱 | 图谱可视化直观 | 单一功能 | 3D 引用图谱嵌入阅读器联动 |
| Zotero | 文献管理 | 开源、插件生态强 | 无 AI 分析能力 | AI 原生 + RAG 知识沉淀 |
| Overleaf | 论文协作写作 | LaTeX 协作成熟 | 无 AI 创作与检索 | AI 写作 + 全流程数据打通 |
| 知网研学 / 百度学术 | 中文文献检索 | 中文资源强 | AI 弱、界面传统 | 中文友好 + 强 Agent 智能体 |
| Paperpal / Jenni / 讯飞科研助手 | AI 写作润色 | 润色降重能力强 | 只管写作 | 写作与选题/实验/投稿联动 |
| ChatGPT / Claude / Kimi / 豆包 | 通用大模型 | 通用能力强 | 无科研工作流与专业工具 | 专业科研工作流 + 可接入任意模型 |
| NotebookLM | 文档问答 | 来源可溯源 | 无科研专用功能 | 科研场景深度定制 + 团队协作 |

**竞品结论**：通用大模型有「脑」无「手」（缺专业工具），垂直工具有「手」无「脑」（缺智能体编排）。ScienceX 的机会 = 以专业 Agent 对话为中枢，把科研专用工具全部智能体化、流程化。

## 🤖 四、项目中 AI 具体的应用与价值

| 环节 | AI 能力 / 模型 | 具体应用 | 对用户的价值 | 关键技术 |
| --- | --- | --- | --- | --- |
| 对话中枢 | 多厂商 LLM（DeepSeek V4 Pro / Claude / Gemini / Kimi / Qwen / Grok） | 意图理解、任务编排、工具调用、8 种 Agent 模式执行 | 一句话驱动全流程 | Function Calling + Agent 编排 + SSE 流式 |
| 选题 | LLM + 趋势分析 | 选题推荐、可行性评估、综述与开题报告生成 | 快速锁定高价值选题 | 多源检索 + Prompt 工程 |
| 文献检索 | 向量检索 + 语义去重 | arXiv/S2/OpenAlex 聚合排序 | 少看无用文献 | Embedding + ANN |
| 文献阅读 | 长上下文 LLM + 版面解析(PDF/CAJ) | 翻译、思维导图、七段式总结、引用图谱 | 精读效率翻倍 | 文档解析 + 长上下文 |
| 论文问答 | RAG + 三层记忆 | 针对论文深度问答、跨会话记住研究背景 | 读不懂随时追问，越用越懂你 | rag.js + memory.js |
| 实验设计 | LLM + 实验模板 | 消融/对比方案矩阵、SOTA 对标 | 方案更科学、少走弯路 | Prompt + 数据聚合 |
| 数据分析 | 生图模型（gpt-image-2）+ Vision LLM | 两阶段科研图生成、图表解读与建议 | 会画图、看懂图 | 图像生成 + 多模态理解 |
| 论文写作 | LLM + 学术语料 | 互译、润色、查重、降重 | 表达地道、过审率更高 | 改写 + 语义一致性校验 |
| 复现 | 代码理解 Agent（CodeAct） | 解析论文代码、生成环境步骤、比对基线 | 复现门槛大幅降低 | 代码执行 + 异步任务 |
| 评审 | 多 Agent 协作 | 五角色并行盲审、冲突归纳 | 投稿前先「过一遍审」 | 多智能体编排 |
| 投稿 | 向量匹配 + 结构化知识库 | 期刊推荐、deadline 提醒 | 投对期刊、不错过截稿 | 推荐 + 定时任务 |
| 可靠性 | 模型网关韧性层 | 上游超时/空响应兜底、思维链回退、降级重试 | 服务稳定不中断 | resilience.js + fallbacks + streamAdapter |

**AI 价值总结**：AI 承担 **理解 → 检索 → 分析 → 生成 → 校验 → 协作** 全链路工作，自动化科研 60%+ 重复劳动；通过 **引用溯源 + 多智能体互检 + 网关降级** 保证可信与稳定。

| **后端（AI）** | AI 服务 | **Python + FastAPI**（Agent 编排、RAG、文件解析 PyMuPDF） | ✅ 部分交付（Node AI 服务层 + 可选 Python 解析） |
| | 模型网关 | OpenAI 兼容协议，双通道：OpenAI Next（多厂商）+ Sophnet（DeepSeek 默认），生图通道 gpt-image-2 | ✅ 已交付 |
| | Agent 引擎 | 灵犀引擎：8 种 Agent 模式、3 层记忆、MCP 编排、韧性降级 | ✅ 已交付 |
| | 实时通信 | SSE 七类事件流 + 异步任务轮询（createTask → resultBuilder → done） | ✅ 已交付 |
| **数据层** | 持久化 | JSON Store（`.data/store.json`，原子写+临时文件） | ✅ 演示交付 |
| | 目标存储 | PostgreSQL 16 + Redis 7 + pgvector/Milvus + MinIO/S3 | 🎯 目标 |
| **安全** | 鉴权/防护 | HMAC Token（sx1.）、密码校验、限流分桶、密钥仅存 .env | ✅ 已交付 |
| | 企业级演进 | OAuth2/SSO + KMS 密钥加密 + 审计日志 | 🎯 目标 |

**关键技术决策**：

| 决策点 | 方案 | 理由 |
| --- | --- | --- |
| 前后端分离 | React/TS ↔ REST/SSE | 独立迭代、多端复用，移动端与桌面共用 API |
| 后端双语言演进 | Java 业务 + Python FastAPI AI | 业务稳定与 AI 生态各取所长 |
| 模型接入 | OpenAI 协议兼容 + 网关路由 | 用户自由接入任意大模型，抗单一厂商风险 |
| 流式交互 | SSE | 对话与任务进度实时逐帧渲染，成本低 |
| 移动适配 | 响应式 CSS + 断点体系 | 低成本覆盖移动场景 |
| 可扩展 | Skills / MCP / 自定义模型 | 生态开放，能力持续扩展 |

## 🔄 六、用户操作流程

| 2️⃣ 入门 | 注册（密码 ≥6 位）→ 登录 → 填写研究方向与偏好 | account 路由 + 个人中心·资料偏好；初始化工作台 | 个性化账号 |
| 3️⃣ 配置 | 在「模型管理」选择内置模型或接入自定义 OpenAI 兼容模型 | 网关校验 Key 与可用性（timeout/api_key_env） | 可用模型列表 |

| 7️⃣ 实验 | 生成消融/对比方案 → 记录参数看板 → 对标 SOTA | 实验设计模块 | 实验方案 + 参数记录 |
| 8️⃣ 分析 | 提示词生成科研图（10 类模板）→ AI 解读图表给建议 | 数据图表 FigureStudio | 科研图表 + 分析结论 |
| 9️⃣ 写作 | 润色 → 查重 → 降重（前后对比）→ 中英互译 | 论文写作模块 | 论文定稿素材 |
| 🔟 复现 | 提交论文+代码仓库 → 异步复现任务 → SSE 进度 → 复现报告 | 论文复现 DreamPaper | 环境指南 + 基线比对 |
| 1️⃣1️⃣ 预审 | 提交专家评审团 → 五角色并行盲审 → 冲突分析与修改优先级 | 多智能体评审 | 模拟审稿报告 |
| 1️⃣2️⃣ 组会 | 一键生成 PPTX → 记录导师建议并归档待办 | 组会汇报 | 组会 PPT + 建议清单 |
| 1️⃣3️⃣ 投稿 | 查 CCF 期刊 → 设倒计时 → 期刊匹配推荐 | 投稿助手 | 目标期刊 + 提醒 |
| 1️⃣4️⃣ 沉淀与续费 | 成果入团队知识库；查看用量统计；升级 Pro/Team 订阅 | RAG 知识库 + 个人中心·用量/订阅 | 团队资产 + 订阅状态 |

**主流程一句话**：`注册 → 配置模型 → 建课题 → 选题 → 读文献 → 实验 → 图表 → 写作 → 复现 → 预审 → 组会 → 投稿`，数据全程自动回流课题空间。
